This portfolio was built to collect my work, experience, and project stories in one place. It focuses on presenting development and design work through responsive pages, content sections, and interactive details.

The site uses Astro for fast static pages and flexible components. It also includes reusable layouts, project sections, markdown content, page transitions, and small interactive features that make the site feel more polished.

**Key work**

- Built reusable Astro layouts and page sections
- Created responsive project, journey, and contact pages
- Added interaction details like cursor-follow previews and animated sections
- Organized content so future projects can be added more easily
