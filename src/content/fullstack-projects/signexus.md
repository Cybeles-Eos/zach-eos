caseStudySections:
  - id: overview
    label: Overview
    title: Designing a large dashboard platform built around doctors and learning.
    paragraphs:
      - SigNexus is a subscription platform designed for doctors and medical professionals. It brings different learning and community tools into one dashboard where users can read, study, share knowledge, join discussions, and access medical content. The project included many connected pages, so keeping the dashboard simple and consistent was an important part of the design.
      - I worked as part of the design team and handled several dashboard pages in Figma. My work covered different parts of the platform, including Forums, Blogs, Podcasts, Research, Medico-Legal Cases, Language Training, Medical Mock Exams, Case of the Week, Tutoring, and Interview Prep.
      - Each feature needed more than one screen. I designed listing pages, detail views, forms, filters, search areas, cards, sidebars, and different states based on how the feature worked. I also had to think about what information should appear first and how users would move from one screen to another.
      - Some features went through several revisions before reaching the approved design. After receiving feedback, I reviewed the requested changes and updated the layout, content placement, spacing, components, or user flow. I then checked the other related screens to keep the design consistent.
      - I also worked with existing components and design patterns from the project. Instead of making every page look different, I reused familiar layouts where they made sense and adjusted them based on what each feature needed.
      - Because the platform had many features, I had to understand the purpose of a page before designing it. A forum needed a different flow from a mock exam, while tutoring and interview prep needed clear booking and subscription actions. Understanding these differences helped me decide how each screen should be arranged.

  - id: what-i-build
    label: What i build
    title: Designing dashboard pages for different medical learning features.
    paragraphs:
      - I created Figma layouts for several parts of the SigNexus dashboard. This included Forums where users can create and join discussions, Blogs for medical content, Podcasts for audio learning, and Research pages where doctors can browse and read medical research.
      - I also worked on Medico-Legal Cases, Language Training, Medical Mock Exams, and Case of the Week. These pages needed different layouts for listings, categories, filters, details, progress, and actions while still following the same dashboard design.
      - Other designs included Tutoring and Interview Prep. These sections focused more on finding professionals, viewing information, checking schedules, and requesting or booking sessions. I designed the screens around the steps users would need to complete these actions.

  - id: design-process
    label: Design process
    title: Taking each feature from a task to an approved Figma layout.
    paragraphs:
      - Before starting a page, I first reviewed the feature and the information it needed to show. I then planned the layout in Figma using the existing dashboard structure and components. Once the first design was ready, it was reviewed and I received revisions when changes were needed.
      - I applied the revisions and checked related screens before sending the updated design for another review. Some pages needed small changes while others needed a different layout or flow. I continued updating the designs until the required screens were ready and approved.

  - id: stack
    label: Stack
    title: The design tool and system I used throughout the project.
    paragraphs:
      - This project was fully focused on Figma. I used it to create dashboard layouts, components, cards, forms, filters, content sections, detail views, and different page states. I also followed the existing design system so new screens stayed consistent with the rest of the SigNexus dashboard.

  - id: revisions
    label: Revisions
    title: Updating page content based on review and feedback.
    paragraphs:
      - Revisions were a regular part of this project. After each review, I received updates on the content that needed to be added, removed, or changed on my assigned pages. This included missing information, new fields, labels, sections, actions, and details needed for each feature. I updated the Figma screens based on the feedback and reviewed the pages again to make sure all required content was included.

  - id: what-i-learn
    label: What i learn
    title: Learning how to design a large dashboard with many different features.
    paragraphs:
      - SigNexus gave me more experience working on a large Figma project where many features had to feel like parts of the same system. I learned to think beyond a single page and consider how listing pages, detail views, forms, filters, actions, and different states connect with each other.
      - It also improved how I handle feedback and revisions. Working on many dashboard pages taught me to reuse patterns when possible, keep layouts consistent, and understand the purpose of a feature before deciding how the interface should look.
