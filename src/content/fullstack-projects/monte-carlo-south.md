  - id: overview
    label: Overview
    title: Building a complete website for an automotive service business.
    paragraphs:
      - Monte Carlo South is an automotive service website built to present its main services in one place. The website covers auto painting, mechanical work, body repair, carwash, detailing, and other auto care services. I handled the project on my own from the first Figma layouts to the completed static frontend pages.

  - id: what-i-build
    label: What i build
    title: Handling the website from the first design to the final pages.
    paragraphs:
      - I started by planning the website structure and creating the page designs in Figma. I worked on the layout, sections, service content, buttons, images, and overall style before moving into development. The goal was to give the automotive business a clean website where customers could quickly understand the services they offer.
      - After finishing the designs, I turned them into static frontend pages. I built the sections based on my Figma layouts and worked on the navigation, service sections, content blocks, buttons, images, and other parts of the website.
      - I also made the pages responsive so the content would work properly across desktop, tablet, and mobile screens. Since I handled the project alone, I was responsible for keeping the design and frontend consistent from start to finish.

  - id: stack
    label: Stack
    title: The tools and technologies I used to build the website.
    paragraphs:
      - I used Figma to plan and design the website before development. For the static frontend, I used HTML, SCSS, CSS, and JavaScript to build the page structure, styling, responsive layouts, and interactions based on the designs I created.

  - id: what-i-learn
    label: What i learn
    title: Managing a complete design and frontend project on my own.
    paragraphs:
      - Monte Carlo South gave me more experience handling a website without relying on a team for the design or frontend work. I had to plan each page, make design decisions, build the layouts, and check my own work. It helped me improve how I manage my workflow from Figma to the final static website.
    highlight: This project gave me full responsibility for the design and frontend process while improving my Figma, HTML, SCSS, CSS, JavaScript, responsive design, and project planning skills.
