  - id: overview
    label: Overview
    title: Building a platform that connects families with care providers.
    paragraphs:
      - Health Is Wealth Living is a care service platform built to connect families with nurses, caregivers, housekeepers, and other care providers. Users can browse providers, view their profiles, and find the care service they need. I worked mainly on the frontend while also helping with some backend features and connecting system data to the website.

  - id: what-i-build
    label: What i build
    title: Building the website pages, provider features, and dashboard.
    paragraphs:
      - I worked on the frontend for different parts of the website, including the main pages, provider listings, provider profiles, and dashboard sections. I turned the provided designs into working responsive pages and made sure each section followed the planned layout.
      - I also helped with some backend work needed for the system features. This included connecting frontend pages with system data and working on parts of the provider and booking features. This gave me experience working across both the frontend and backend of the same project.
      - For the provider listing, I worked on search, filters, provider cards, specialties, rates, and other details shown to users. I also worked on dashboard pages where providers can view bookings, manage availability, and access their account information.

  - id: stack
    label: Stack
    title: The tools and technologies we used to build the platform.
    paragraphs:
      - We used Laravel for the main system and MySQL for storing and managing data. For the frontend, we used JavaScript, jQuery, SCSS, CSS, and Bootstrap to build responsive pages and dashboard components. Figma was used as the design reference while turning the layouts into working pages.

  - id: what-i-learn
    label: What i learn
    title: Working across frontend and backend on the same project.
    paragraphs:
      - This project gave me more experience working beyond static frontend pages. I learned more about connecting frontend components with backend data and understanding how provider profiles, bookings, and dashboard features work together. It also improved how I build responsive pages for different types of users.
