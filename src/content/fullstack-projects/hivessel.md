    title: From Figma layouts to working pages for the Hivessel website.
    paragraphs:
      - I worked on different Hivessel pages starting from Figma design. This included homepage concepts, lesson pages, service listings, and service detail pages. I planned the layout based on the content each page needed while keeping the same design style across the website.
      - After the designs were reviewed, I worked on turning the approved layouts into frontend pages. I focused on the page structure, cards, sections, navigation, spacing, and responsive layouts while keeping the frontend close to the original Figma design.
      - Some pages needed different layout options before we chose the final design. I created and reviewed different versions in Figma so we could compare how the content looked before moving forward with development.
