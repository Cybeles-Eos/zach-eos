      - I created the website as a static frontend project with pages for Filipino recipes and food content. I worked on the page structure, navigation, recipe sections, images, buttons, and other basic parts of the website. Since this was an early project, I focused on learning how a complete website fits together.
      - I also wrote and organized the content shown across the website. Working on both the code and content helped me understand how design, text, images, and page structure need to work together to make a website easy to use.
